Nuevo evento

Un evento agrupa las unidades de una subasta. Asigna qué clientes lo ven. Importa las unidades con un CSV con columnas: ref, marca, modelo, anio, km, cuerpo, zona, estado, condiciones, casa, lote, vin, no_economico, ubicacion, url (condiciones separadas por “;”). Casa, lote, VIN, ubicación y URL quedan solo para administradores.

Subir carpeta de fotos

Selecciona la carpeta que contiene una subcarpeta por unidad con el nombre de su referencia (AL-01, AL-02…). Las fotos se guardan en almacenamiento privado y la lista de fotos de cada unidad se actualiza sola. Los archivos que empiezan con “t_” se usan como miniaturas.
